# Apple Pay webhook

Приёмник платежей из iOS Shortcut после Wallet Transaction Automation. Платёж сохраняется, получает расходную категорию Дзен-мани и, когда для этого хватает данных, уходит в Дзен-мани как расход.

Сервис целиком живёт на бесплатном тарифе Cloudflare: Workers, D1 и Zero Trust. Платить не нужно. От вас нужен только домен, привязанный к Cloudflare и проксируемый через него. Своего сервера нет. Платные продукты Zero Trust не включаются: Gateway, WARP, проверка устройства, Browser Isolation. Около тысячи платежей в месяц в бесплатные лимиты укладывается.

```
Apple Pay → Shortcut → POST /w/<WEBHOOK_ID>
                              ↓
                           Worker
              ├─ D1
              ├─ debug-бот: сырой запрос
              ├─ NotifyBot: одна строка о платеже
              ├─ /admin: категории, продавцы, карты
              └─ Дзен-мани: расход, если карта и категория уже известны
```

## Свой хост

Скопируйте `worker/wrangler.toml.example` в `worker/wrangler.toml` и укажите маршрут своего домена. Зона должна быть на том же аккаунте Cloudflare и проксироваться через него. Файл с маршрутом и id базы в git не входит.

Webhook, `GET /health` и портал живут на этом хосте. Cloudflare Access закрывает только `/admin` и `/admin/*`. Весь хост закрывать нельзя: Shortcut перестанет доходить до webhook.

## Секреты

```bash
cp .env.example .env
openssl rand -hex 32
```

Вставьте 64 строчных hex-символа в `WEBHOOK_ID`. Остальное:

- `DEBUG_BOT_TOKEN` и `DEBUG_CHAT_ID` — debug-бот. Туда приходит сырой webhook, итог ручного синка категорий и кнопка `Sync categories`. Пустые значения отключают бота, приём платежей от этого не ломается.
- `NOTIFY_BOT_TOKEN` и `NOTIFY_CHAT_ID` — NotifyBot. Туда уходит только строка о новом платеже. Пустые значения отключают эти сообщения.
- `TIMEZONE` — часовой пояс IANA, например `Europe/Belgrade`. Время в NotifyBot и дата операции в Дзен-мани берутся из него. Пустое значение означает UTC.
- `SHOW_CARD_NAME` — `1` добавляет в NotifyBot имя карты. `0` его убирает. Пустое значение показывает карту.
- `ZENMONEY_TOKEN` — bearer аккаунта Дзен-мани. Токен можно получить у любого сервиса, который уже зарегистрирован в Дзен-мани. Например, [Zerro.app](https://zerro.app/token). Пустой токен не попадает в секреты воркера: категории, счета и отправка расходов тогда не работают.

`.env` не коммитить. В логах путь запроса содержит `WEBHOOK_ID`.

### Токены ботов и id чата

В Telegram откройте [@BotFather](https://t.me/BotFather) и дважды выполните `/newbot`: один бот для сырых сообщений, второй для коротких. BotFather пришлёт токен вида `123456789:AAH...`. Первый запишите в `DEBUG_BOT_TOKEN`, второй в `NOTIFY_BOT_TOKEN`.

Id чата в личной переписке совпадает с id пользователя. Напишите каждому боту любое сообщение, затем откройте в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

В ответе возьмите `message.chat.id`. Это число и есть `DEBUG_CHAT_ID` или `NOTIFY_CHAT_ID`. Если оба бота пишут одному человеку, id одинаковый. Пока боту ничего не написали, `getUpdates` пустой.

## Деплой

```bash
wrangler login
./worker/deploy.sh
```

Скрипт создаёт базу D1 в Западной Европе, если её ещё нет, применяет `worker/schema.sql`, записывает секреты и публикует воркер. Повторный запуск обновляет секреты и схему. Для debug-бота регистрируется webhook `POST /t/<WEBHOOK_ID>` и сразу показывается кнопка `Sync categories`.

В Shortcut уходит `POST` на `/w/<WEBHOOK_ID>`.

## Настройка на iPhone

Команда и автоматизация Wallet настраиваются на каждом телефоне и для каждой карты отдельно.

1. **Команда.** Команды → Все команды → +. Название, например `Apple Pay Webhook`. Добавьте действие «Получить содержимое URL»: метод `POST`, заголовки пустые, тело запроса `JSON`, адрес `https://<ваш-домен>/w/<WEBHOOK_ID>`.

2. **JSON.** В теле пять полей. Значения — не текст, а свойства «Входных данных команды» / Shortcut Input:

```
amount       → Amount
transaction  → Transaction
name         → Name
card         → Card or Pass
merchant     → Merchant
```

`Amount` отправляйте как есть, строкой. Wallet может отдать `1.250 RSD`, `$12.50` или `15,00 €`. Если положить сумму в словарь как число, она часто превращается в `0`.

3. **Вход команды.** В настройках команды включите получение входных данных. Берите именно «Входные данные команды» / Shortcut Input. Действие «Запросить входные данные» спрашивает значение у человека и для оплаты не подходит.

4. **Автоматизация.** Команды → Автоматизация → + → Транзакция / Transaction. Выберите нужную карту и все категории продавцов, если нужны все расходы. Фильтр конкретных продавцов не задавайте.

5. **Связка.** В автоматизацию добавьте «Запустить команду» / Run Shortcut и выберите `Apple Pay Webhook`. На вход передайте транзакцию от Wallet. Без неё команда запустится, но `Amount`, `Merchant` и `Card` взять будет неоткуда.

6. **Без подтверждения.** Поставьте «Запускать немедленно» / Run Immediately. Вариант с подтверждением после каждой оплаты спрашивает разрешение.

7. **Проверка.** Оплатите что-нибудь этой картой через Apple Pay. На webhook придёт JSON с этими полями. Сумма придёт в том виде, как её показывает iOS.

```
Оплата Apple Pay → Wallet Transaction → автоматизация → команда → POST /w/<WEBHOOK_ID>
```

## Платёж

Неверный `WEBHOOK_ID` и неизвестный путь отвечают 404. Сравнение идентификатора побайтовое. `GET /health` отвечает `{"status":"ok"}` без входа.

Webhook принимает любое тело. Платёж создаётся, если в JSON есть хотя бы одно из полей `amount`, `transaction`, `name`, `card`, `merchant`. Ожидаемая форма Shortcut, все поля строки:

```json
{"amount":"1.234,56 RSD","transaction":"","name":"","card":"","merchant":""}
```

`amount` разбирается как сербская запись: точка отделяет тысячи, запятая — дробь, в конце через пробел код валюты. В базу сумма пишется числом с точкой (`1234.56`), код — в `currency`. Между числом и кодом iOS часто ставит неразрывный пробел, он тоже подходит. Сырой JSON остаётся в `raw`.

Имя продавца — поле `name`. Если оно пустое, берётся `merchant`. Сравнение без учёта регистра: `YANDEXTAXI` и `yandextaxi` — один продавец. Новый продавец появляется без категории. Если для этого имени категория уже задана, она сразу ставится платежу.

Ответ `{"ok":true}`, пока запись в D1 прошла. Сбой записи — лог и `{"ok":false}` с кодом 500. Сбой Telegram и сбой Дзен-мани ответ webhook не меняют.

## Дзен-мани

Категории и счета забираются через `POST /v8/diff/`.

Категории обновляются кнопкой `Sync categories` в debug-боте, запросом `POST /z/<WEBHOOK_ID>` и cron раз в час (`0 * * * *`, UTC). В снимок попадают только расходы, у которых `showOutcome` истинно. Сообщение `получено N новых N` уходит в debug-бот только по кнопке и по `POST /z/`. Часовой синк молчит. Чужой чат и запрос без секретного заголовка Telegram синк не запускают.

Счета обновляются только кнопкой «Синхронизировать счета» на вкладке «Карты». Сами они не подтягиваются.

Расход уходит в Дзен-мани, когда собраны три вещи: карта из платежа связана со счётом, у продавца есть категория, валюта платежа совпадает с валютой счёта. Это один и тот же счёт в полях списания и зачисления, сумма в `outcome`, `income` равен 0, категория и имя продавца. Дата — календарный день в `TIMEZONE`. Свой id операции хранится на платеже, повтор ту же трату не создаёт. Нет карты или категории — платёж ждёт и уходит, когда их задали. Смена категории у уже отправленной траты обновляет ту же операцию. Курсы валют не подставляются.

## Боты

Debug-бот получает сырой запрос. Длинное сообщение режется кусками.

NotifyBot получает одну строку, и только если платёж записан:

```
📅 DD-MM-YYYY HH:MM 💳 <карта> 🏪 <продавец> 🏷 <категория> 💰 <сумма> <валюта> ☯️ ✅
```

`💳` есть только при `SHOW_CARD_NAME=1`. Если категории нет, слова «без категории» ведут на `/admin`. `☯️ ✅` — расход записан в Дзен-мани. `☯️ ❌` — не записан.

## Портал

`/admin` — список с телефона. Три вкладки, в скобках число ещё неразмеченных.

- **Платежи.** Сначала без категории, если такие есть. Нажатие открывает поиск по расходным категориям, выбор сразу сохраняется и запоминается за продавцом.
- **Продавцы.** Имя, как в поле `name`, и категория. Правило можно вписать руками. Сохранение ставит категорию всем платежам этого имени, включая уже размеченные. «Убрать» удаляет правило и не снимает категорию с платежей, которые уже размечены.
- **Карты.** Имя карты из платежа и счёт Дзен-мани. Счёт выбирается из списка после синхронизации, id вручную не вводится.

Вход делает Cloudflare Access, не код приложения. Пока запрос не прошёл Access, воркер сам отвечает 403.

### Cloudflare Access

Нужен бесплатный Zero Trust. Gateway, WARP, проверка устройства и Browser Isolation не включайте.

1. В панели Cloudflare откройте **Zero Trust**. При первом заходе задайте имя команды. Логин потом будет на `<команда>.cloudflareaccess.com`.
2. **Access controls** → **Applications** → **Create new application** → **Self-hosted and private** → **Add public hostname**.
3. Добавьте два публичных имени на одном приложении, оба на ваш домен: путь `/admin` и путь `/admin/*`. Маска не покрывает точный `/admin`, поэтому нужны оба. Имя без пути не добавляйте: иначе закроется весь хост и Shortcut не дойдёт до webhook.
4. Политика **Allow**, правило **Include**, селектор **Emails**, почта того, кто будет открывать админку с телефона. Один такой вход занимает одно место из 50.
5. Способ входа — **One-time PIN**: код приходит на эту почту, отдельный провайдер не нужен. Если провайдер один, включите **Apply instant authentication**, чтобы не показывать промежуточную страницу выбора.
6. **Session duration** поставьте несколько дней, например `168h`, чтобы не входить заново каждый раз.
7. **Create**.

Проверка: `GET /health` остаётся `200`, `GET /admin` уходит на страницу входа Access, чужая почта не проходит.

## База

- `requests` — сырые webhook.
- `payments` — поля Shortcut, сумма, валюта, категория, id операции Дзен-мани и сырой JSON. Колонка `transaction` в SQL в кавычках: это зарезервированное слово.
- `merchant_rules` — продавец и его категория. Пока продавца не разметили, категория пустая. Ключ — имя в нижнем регистре.
- `zenmoney_tags` — расходные категории.
- `zenmoney_accounts` — счета после ручной синхронизации.
- `card_accounts` — имя карты из Shortcut и id счёта.

Логи воркера смотрят через `wrangler tail`. Отдельного хранилища логов нет.
